      데이터 출처

      화합물의 구조, 분자식, 분자량, GHS 유해성 정보는 PubChem의 공개 API(PUG REST)에서 실시간으로 불러옵니다. ChemSpider는 교차 확인용 외부 링크로 함께 제공됩니다.

      혼합 위험 판정 방식

      두 물질의 조합이 자체 구축한 알려진 위험 조합 목록(락스+암모니아 등 공식적으로 널리 알려진 사례)에 있는지 확인합니다. 목록에 없다면 "알려진 사례 없음"으로 표시되며, 이는 안전을 보장하지 않습니다.

      한계와 주의

      임의의 두 화학물질이 만났을 때 어떤 반응이 일어날지 자동으로 예측해주는 공개 데이터베이스는 존재하지 않습니다. 이 도구는 참고 자료일 뿐이며, 실제 취급 전에는 물질안전보건자료(MSDS)와 전문가의 확인이 반드시 필요합니다.

      데이터: PubChem PUG REST API · ChemSpider(외부 링크) · 이 사이트는 정보 제공 목적이며 실제 안전 판단을 대체하지 않습니다.
